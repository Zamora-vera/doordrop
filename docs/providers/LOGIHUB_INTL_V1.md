# LogiHub Internacional (DO → mundo)

## Scope
- Solo cotiza/crea si **origen = DO**
- Servicios: Estándar (`international_economy`) y Express (`international_priority`)
- Logo: https://logihub.tech/docs/v2/images/logo.png
- ETA en delivery.min_days / max_days

## Config
```env
LOGIHUB_API_KEY=lhk_...
LOGIHUB_WEBHOOK_SECRET=...
LOGIHUB_ALLOW_REAL_BUY=true
LOGIHUB_BASE_URL=https://my.logihub.tech/api/v2
```

Webhook: https://ship24go.com/api/webhooks/logihub

Docs: https://logihub.tech/docs/v2/internacional/
