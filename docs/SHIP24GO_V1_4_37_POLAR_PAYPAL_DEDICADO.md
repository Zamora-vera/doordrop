# Ship24Go V1.4.37 — Polar y PayPal dedicados

## Cambio

- Polar se mueve a `/admin/polar`.
- PayPal se mueve a `/admin/paypal`.
- `/admin/settings` queda limpio para configuración general.
- `/admin/plans` queda enfocado en precio, descuento y estado del plan.
- Las páginas dedicadas incluyen configuración, salud, historial y sincronización de planes.

## Rutas

- `/admin/polar`
- `/admin/paypal`
- `/admin/banks` para wallet y transferencias.
